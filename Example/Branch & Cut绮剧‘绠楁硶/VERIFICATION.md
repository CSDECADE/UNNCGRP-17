## 自动测试

`tests/test_external_start.py` 包含 6 项测试：

1. 七个原文件哈希一致。
2. 12 个小实例逐一比较原核心冷启动、新外部 warm start 与独立穷举最优值；全部一致。24 次 COPT 求解均返回最优状态，联合相对和绝对 gap 限制均为 0，保存上下界数值相符。个别重算 gap 为浮点舍入量级，因此按 `1e-12` 检查，而不是伪改写为 0。每个最终解通过独立原始数据检查。初始解均被进一步改进，验证其决策没有被固定。测试还强制禁止内部 two-step 求解调用。
3. 错误目标、错误分母、错误哈希、非法路径、缺失照片、错误方法、缺失/负数/非数时间，以及遗漏第一阶段历史耗时的种子均在进入 COPT 前拒绝。
4. 历史耗时确实为 0 时允许使用，不以真值判断误拒绝。
5. 异常后恢复 COPT 资源参数；初始解未提交时拒绝悄悄冷启动。
6. 真正通过批量入口启动独立 Python 子进程，检查输出、日志、约束报告、时间求和、SHA-256、覆盖保护和缺失种子处理。
