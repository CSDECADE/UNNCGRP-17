# 多机路径分析

打开内置示例，点击「多机路径分析」，查看每架无人机的拍摄点数、航线长度和时长，以及任意两架无人机的最近模拟间距和出现时刻。间距阈值只用于标记结果。

距离以米计。全部拍摄点有时间戳时按方案时间计算，否则按基础工程规则，每条航线相邻拍摄点间隔 6 秒。拍摄点之间按直线插值；到达前和到达后分别保持在首末拍摄点。没有拍摄点的无人机不参与间距比较。

此模块独立提供「导入候选航线 JSON」，不依赖项目文件或播放模块。候选文件形如 `{ "version": 1, "viewpoints": [...] }`；每个拍摄点的 `droneId` 必须与当前场景匹配。导入后可以比较总航程，应用后才替换当前航线。取消不会修改项目。

此版本仅增加多机路径分析与候选方案导入。它不生成最优路线，也不启用项目文件导出、手动调整或动态可视化模块。
