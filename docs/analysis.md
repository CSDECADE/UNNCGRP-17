# 鲁逸尘 · 多机路径分析

先解压基础工程，再将本包解压到同一个工程根目录。重新运行 `npm run dev`。

`index.tsx` 提供按无人机汇总、方案接收、候选方案预览与应用。接入已有算法时，以当前项目为输入，通过 `acceptPlan` 接收结果。基础工程的 `importPlan` 负责数据验证。文件选择与下载由导出模块提供。

算法文件为 `{"version":1,"viewpoints":[...]}`。拍摄点字段为 `id`、`name`、`droneId`、`position`、`target`，可含 `time`。坐标为米，Y 轴向上，时间为相对方案起点的秒数。同一架无人机的时间应全部提供且严格递增。

后续接入已有算法并补充结果指标。当前起点提供手动导入和路线汇总。验收时导入两架无人机的合法方案，检查取消保留原方案、应用后可撤销、无效 ID 被拒绝。
